# Contagem de Inventário — EPI & Uniformes (v2.1)

Ferramenta web para contagem de inventário (EPI, uniformes, segurança).

## Finalizar e enviar pelo WhatsApp

Ao clicar em **Finalizar contagem**:

1. O Excel é gerado e **baixado no aparelho**.
2. Aparece a opção **Enviar no WhatsApp**.
3. No celular, o sistema abre o compartilhamento com o **arquivo Excel** — escolha o WhatsApp e o grupo.
4. No computador, abre o WhatsApp com a mensagem pronta; anexe o Excel que acabou de baixar.

Não depende de e-mail nem de serviços externos que possam parar de funcionar.

## Contagem salva no aparelho

A contagem fica salva se a página for fechada por acidente. Só some ao **Limpar tudo** ou ao **Finalizar**.

## GitHub Pages

Publique o `index.html` em um repositório e ative Pages (branch main / root).
